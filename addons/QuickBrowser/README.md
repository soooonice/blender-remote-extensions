# QuickBrowser 使用说明

## 打开和浏览

启用插件后，点击任一区域左上角的编辑器类型菜单，选择 QuickBrowser。双击场景、集合或对象进入下一级。在浏览器内容区按 Tab 返回上一级。使用顶部搜索、类型过滤和展开按钮查找数据。

## 选择与编辑

- 单击选择，Ctrl 单击切换选择，拖动空白区域框选。
- F2 重命名，Ctrl+F2 批量重命名。
- 对象下的材质按实际插槽顺序显示。同一材质出现多次时，每张卡片对应一个插槽。
- 在对象下选中材质按 X 移除对应插槽。Shift+X 会从文件中删除数据块，并影响它的所有引用。
- 双击图片或点击材质的编辑按钮，优先使用已有的匹配编辑器。复用已有编辑器时，鼠标保持原位，Pin 和 Tab 遵循 Blender 默认行为。仅在浏览器区域临时切换为编辑器时，按 Tab 返回浏览器。

## 拖放

将对象拖到 3D 视图可创建副本，多选拖放保留相对位置。将材质拖到对象上会替换首个材质插槽。将对象拖到浏览器内的集合可以调整归属。

## 对象预览

默认显示灰模。使用右上角按钮统一切换灰模或材质模式；卡片右下角按钮单独切换该对象。编辑模式期间保留原预览，退出后合并刷新。右侧滑块可拖动，底栏仅在刷新期间显示进度。
