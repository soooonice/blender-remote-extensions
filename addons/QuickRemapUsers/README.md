# QuickRemapUsers

批量将所选同类型数据块的使用者重新映射到一个目标数据块。

版本：1.0.0。Blender Extension，最低版本配置沿用 QuickScene：5.2.0；运行验证版本为 5.3.0 Beta。

## 使用
1. 将 Outliner 显示模式切换为 Blender File。
2. 选择一个或多个同类型数据块。
3. 按 R，选择 Remap To 目标，再点击 Remap。

源数据块不会被自动删除；目标本身若也被选中会跳过。操作支持撤销。
通过 Preferences > Get Extensions > Install from Disk 安装 ZIP。
